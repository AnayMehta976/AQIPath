# Contributing to AQIPath

Thanks for helping improve cleaner-air navigation.

## Getting started

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Follow the setup steps in the [README](README.md).
3. Make your change with clear, focused commits.
4. Open a pull request describing what changed and why, with screenshots for UI changes.

## Guidelines

- Keep pull requests small and focused.
- Never commit API keys, keystores or `local.properties`.
- Test on at least one physical device or emulator before submitting.
- Be respectful in issues and reviews.

## Reporting bugs

Use the bug report template and include device model, Android version, app version and steps to reproduce.
